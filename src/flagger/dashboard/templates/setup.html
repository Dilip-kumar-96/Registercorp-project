Step 1 — Portal API Token

The bot needs a token to check prior notice statuses on the Registrar Admin portal.

  1. Open tools.registrarcorp.com and log in
  2. Press F12 to open Developer Tools → click Network tab
  3. Click Fetch/XHR filter → click any request in the list
  4. Look at the Request URL — copy the value after token=

Step 2 — Connect Outlook

Option A — Open a browser window and log in once. The session is saved for future runs.

⏳ Waiting for login…
or

Option B — Already logged into Outlook in Chrome? Paste the Bearer token directly.

How to get the token from Chrome (click)
  • Open Chrome → go to https://outlook.cloud.microsoft/mail/pn@registrarcorp.com/
  • Press F12 → Network tab → filter by service.svc
  • Click any service.svc request → Headers → copy Authorization value
  • Optional: Go to Application → Cookies → copy X-OWA-CANARY

From F12 → Network → service.svc → Request Headers → Authorization

From F12 → Application → Cookies → X-OWA-CANARY
