Step 1 — Portal API Token

The bot needs a token to check prior notice statuses on the Registrar Admin portal.

  1. Open tools.registrarcorp.com and log in
  2. Press F12 to open Developer Tools → click Network tab
  3. Click Fetch/XHR filter → click any request in the list
  4. Look at the Request URL — copy the value after token=

Step 2 — Connect Outlook

The bot needs to log in to the shared Outlook mailbox once to get session access. A browser window will open — log in and check "Keep me signed in". The window will close automatically.
