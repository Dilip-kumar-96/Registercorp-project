🔑 Outlook Manual Session

No Chromium login needed — paste tokens directly from your already logged-in Chrome browser. This is the easiest way to set up Outlook on a new machine or fix a broken session.

📖 How to get these values from Chrome (click to expand)
  1. Open Chrome and go to the shared Outlook inbox:
    https://outlook.cloud.microsoft/mail/pn@registrarcorp.com/
  2. Press F12 to open DevTools → click the Network tab
  3. In the filter box, type service.svc to filter requests
  4. Click any service.svc request that appears
  5. In the right panel → Headers → scroll to Request Headers
  6. Find Authorization → copy the full value: Bearer eyJ...
  7. Paste it in the Bearer Token field below and click Test Token
  8. Optional but recommended: Go to Application tab → Cookies → outlook.cloud.microsoft → copy X-OWA-CANARY value
